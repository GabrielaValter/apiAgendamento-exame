# Agendamento Front

Aplicação front-end em Angular para o sistema de agendamentos desenvolvido em Spring Boot.

## Tecnologias

- Angular 20
- Bootstrap (CSS)
- TypeScript

## Requisitos

- Node.js 20 ou superior
- npm (instalado junto com o Node)
- Angular CLI (opcional, mas recomendado)

```bash
npm install -g @angular/cli
